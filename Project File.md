# Download the full project

**The complete F1 Race Predictor, as one folder, is on Google Drive:**

### 👉 [Open the Google Drive folder](https://drive.google.com/drive/folders/1AT_yU_6ySvWNcQNuzkBZ2hiR9vJrsoMC?usp=drive_link)

## What's in it

Everything you need to run the predictor yourself:

- **The code**: all the Python scripts (`run_all.py`, `predict.py`, `train.py` and the rest)
- **The data**: every Formula 1 race since 2014, ready to use
- **The trained models**, so you don't have to train anything before your first run
- **The dashboard**: `index.html`, plus `dashboard.html`, a copy that opens by double-click
- **Double-click launchers** for Windows (`.bat`) and Mac (`.command`)
- **The guides**: `START HERE.txt`, the README, and the setup and code guides

## How to download it

1. Open the link above. You don't need a Google account.
2. Click the folder name at the top, then **Download**. Google Drive packs it into a `.zip` file.
3. Unzip it. On Windows, right-click it and choose **Extract All**. On a Mac, double-click it.
4. Open `START HERE.txt`, or follow the setup guide (`How To Setup.md`).

## Google Drive or GitHub?

| | Google Drive | This GitHub repository |
|---|---|---|
| Best for | Downloading everything in one go | Reading the code and following changes |
| Account needed | No | No (only to contribute) |
| What you get | One zip with the whole project | The same files, browsable online |

Both have the same project. If they ever differ, the newer date wins.
