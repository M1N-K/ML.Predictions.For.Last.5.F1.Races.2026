F1 RACE PREDICTOR - START HERE
==============================

WHAT IT DOES
Predicts the finishing order of Formula 1 races, with each driver's chance of
winning, making the podium and retiring. It also simulates the rest of the
season to estimate the drivers' and constructors' championship odds, and keeps
a record of its own predictions so you can see how it actually did.
Everything is saved as text files in the "Predictions" folder (open in Notepad
or TextEdit).

ONE-TIME SETUP
Install Python from https://www.python.org/downloads
  - Windows: tick "Add Python to PATH" on the first installer screen.

TO USE (no terminal needed)
  Windows:  double-click  Run_Predictions.bat
  Mac:      double-click  Run_Predictions.command
            (first time only: right-click it > Open > Open, because macOS asks
             before running downloaded scripts)

Files that appear in the "Predictions" folder:
  rest_of_season_2026.txt   predicted order + win/podium % for every remaining race
  championship_2026.txt     title odds for drivers and constructors, and when the
                            title could be decided
  scorecard.txt             how past predictions did against the real results
                            (appears after the first predicted race has been run)

AFTER PRACTICE, QUALIFYING OR A RACE (gets the latest results, needs internet)
  Windows:  double-click  Update_And_Predict.bat
  Mac:      double-click  Update_And_Predict.command
  This downloads new data, refits the models, scores the earlier predictions and
  predicts again. The model is more accurate each time more of the weekend is
  known: before the weekend < after practice < after qualifying.

WHO IS RACING
  The tool works out the entry list itself (from the season's official entry list and, after
  practice, who turned up). A one-off stand-in that isn't listed yet can be added in overrides.csv.

CHANGES YOU KNOW ABOUT (driver out, replacement, grid penalty)
  Open overrides.csv in Notepad or Excel, follow the instructions at the top, save it and run
  the predictions again. A grid penalty only has an effect once qualifying has happened.

COMPARE WITH BOOKMAKER ODDS (optional)
  Open odds.csv, add a row per driver (race, stage, source, date, driver, odds), save, then run
  the predictions. Predictions\odds_report.txt shows the model's win chances next to the
  bookmakers'. "python odds.py template 2026-20" makes a blank sheet for a race. Take the odds
  BEFORE the race. A few races cannot show who is better; see MODEL_NOTES.md.

RUN IT BY ITSELF EVERY DAY (optional, not tested on a real machine)
  Windows:  double-click  Schedule_Windows.bat      (once)
  Mac:      double-click  Schedule_Mac.command      (once)
  This keeps the text files in Predictions up to date. The web page is separate: see
  REFRESH_PAGE.md.

WHAT'S IN THE FOLDER
  Predictions/        your text files (start here)
  reports/            accuracy tests, calibration chart, extra outputs
  tracker/            the saved predictions, used for the scorecard
  data/               race data (results, practice, pit stops, sprints since 2014)
  models/             the trained prediction models
  site_data/          the tables behind the web page
  *.py                the code
  README.md           short introduction (MODEL_NOTES.md has the detail: how it works, tests, limits)

HOW TO READ THE PREDICTIONS
  Pred       predicted finishing position
  P(win)     chance of winning that race
  P(podium)  chance of finishing top 3
Roughly how often the model picks the right winner (tested on 191 past races, 2018-2026):
  before the weekend  about 4 in 10
  after practice      about 4.5 in 10
  after qualifying    about 5.5 in 10 (no better than "pole sitter wins"; it is better at
                      ordering the rest of the field)
It is a guide, not a guarantee, and it can't know about crashes, safety cars,
weather or strategy. Not betting advice.

PROBLEMS?
  "python is not recognized": Python isn't installed, or "Add to PATH" was missed.
  Reinstall Python and tick that box. On Windows you can also try "py".
  Anything else: copy the message and ask Claude.
