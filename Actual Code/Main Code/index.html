Do the percentages mean what they say?

When the model says 30%, that should happen about 30% of the time. Each dot groups predictions of similar size and shows how often they came true. Dots on the dotted line mean the percentages can be taken at face value. Groups with fewer than 20 cases are left out.

Predicted and observed frequencies agree to within about one percentage point on average at every stage. A simple correction was tested and did not improve most of them, so none is applied.

This is a statistical model built from public race data (f1db, CC BY 4.0). It cannot know about crashes, safety cars, weather, penalties or upgrades beyond what recent results show. Not betting advice.
